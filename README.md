# 导航管理系统

一个功能完整的网站导航管理系统，支持分类管理、导航项管理、拖拽排序、数据持久化等功能。

## 功能特性

### 基本功能
- ✅ **分类管理**：添加、编辑、删除分类
- ✅ **导航项管理**：添加、编辑、删除导航项
- ✅ **拖拽排序**：支持分类内和跨分类的拖拽排序
- ✅ **数据持久化**：使用 localStorage 保存数据
- ✅ **响应式设计**：适配不同屏幕尺寸
- ✅ **键盘快捷键**：Ctrl+S 保存，Esc 取消

### 高级功能
- ✅ **数据导出**：导出数据为 JSON 文件
- ✅ **数据导入**：从 JSON 文件导入数据
- ✅ **URL 验证**：自动验证 URL 格式
- ✅ **重复检测**：防止重复的分类名称和项目名称
- ✅ **用户反馈**：操作成功/失败的视觉反馈

### 技术栈
- **前端框架**：Vue 3
- **UI 组件库**：Element Plus
- **拖拽库**：SortableJS
- **样式**：CSS3 + 动画效果
- **后端**：Express.js

## 使用说明

### 基本操作

1. **添加分类**
   - 点击"添加分类"按钮
   - 输入分类名称
   - 点击"确定"保存

2. **添加导航项**
   - 点击分类名称展开分类
   - 点击"添加项目"按钮
   - 输入项目名称、URL 和图标
   - 点击"确定"保存

3. **编辑分类**
   - 点击分类右侧的"编辑"按钮
   - 修改分类名称
   - 点击"保存"确认

4. **编辑导航项**
   - 点击项目右侧的"编辑"按钮
   - 修改项目信息
   - 点击"保存"确认

5. **删除操作**
   - 点击"删除"按钮
   - 确认删除操作

### 拖拽排序

1. **分类内排序**
   - 拖拽项目到同一分类内的其他位置

2. **跨分类排序**
   - 拖拽项目到其他分类中

### 数据管理

1. **导出数据**
   - 点击"导出数据"按钮
   - 数据将下载为 JSON 文件

2. **导入数据**
   - 点击"导入数据"按钮
   - 选择 JSON 文件
   - 确认导入操作

### 键盘快捷键

- **Ctrl + S**：保存所有数据
- **Esc**：取消编辑或关闭对话框

## 数据格式

### 分类数据结构
```json
{
  "id": "分类ID",
  "name": "分类名称",
  "items": [
    {
      "id": "项目ID",
      "name": "项目名称",
      "url": "项目URL",
      "icon": "项目图标"
    }
  ],
  "expanded": true
```

## 注意事项

1. **数据安全**：数据保存在浏览器本地，清除浏览器数据会丢失所有信息
2. **备份建议**：定期导出数据作为备份
3. **浏览器要求**：需要支持 ES6+ 的现代浏览器
4. **网络访问**：某些功能需要网络连接（如 URL 验证）

## 故障排除

### 常见问题

1. **页面无法加载**
   - 检查服务器是否启动
   - 确认端口 8081 是否被占用

2. **拖拽功能不工作**
   - 检查 SortableJS 是否正确加载
   - 确认浏览器支持拖拽功能

3. **数据丢失**
   - 检查浏览器是否阻止了 localStorage
   - 确认没有清除浏览器数据

4. **样式显示异常**
   - 检查 CSS 文件是否正确加载
   - 确认浏览器支持 CSS3 特性
